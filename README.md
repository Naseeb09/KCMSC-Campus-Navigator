Welcome to the **ultimate KCMSC campus guide**!  
We started with a lightweight, **CLI-based version** to help students and staff explore classrooms, floors, and key locations — and now we’re going **full app mode** next!  

---

## 🚀 This Release (v1.6.7 – CLI Edition)

- 💻 **CLI Edition:** Navigate the campus right from your terminal  
- 🔍 **Instant search:** Find rooms, classes, or sections in seconds  
- 🏫 **Floor browsing:** Full room lists and highlights for Principal’s office, Teacher rooms, and more  
- 🖼️ **ASCII floor maps:** Built-in maps or fallback “map not available” if missing  
- ⚡ **Smart input handling:** Invalid entries? No problem!  

> 💡 **Next Up:** We’re going **GUI + mobile-friendly app** mode with interactive maps, clickable floors, and real-time navigation. Stay tuned!
